# プリセット: 二人制作 × Ren'Py

「演出担当（シナリオ＋演出）」と「リソース・管理担当」の 2 人で Ren'Py 作品を作る
組み合わせ向けに、汎用ベースへ足す埋め済みセット。

## 取り込み方

1. 汎用ベースでリポジトリを作り、`packs/renpy/` を取り込む。
2. このフォルダの `docs/` の中身をプロジェクトの `docs/` にコピーする。
   ただし置き場所は汎用ベースの構成に合わせる。
   - `FOR_PARTNER.md` → `docs/FOR_PARTNER.md`（演出担当側への配慮メモ）
   - `ROLE_DIRECTOR.md` → `docs/roles/ROLE_DIRECTOR.md`（演出担当の役割メモ）
   - `ROLE_RESOURCE.md` → `docs/roles/ROLE_RESOURCE.md`（リソース・管理担当の役割メモ）
3. `docs/PROJECT.md` の役割表をこの 2 役割で埋め、公開・素材ポリシーを書く。

前提の運用: 演出担当は GitHub 操作をせず報告のみ、push/マージは管理担当。
確認はダミー素材のテスト公開＋自動再生動画、節目だけ本番素材で実機確認。

## その他

- `GUIDE_FOR_PARTNER.md` — 演出担当本人に渡す説明用文書（どういう流れで、
  何ができて、何をしなくていいか）。リポジトリに入れても、そのまま送ってもよい。
