# 役割メモ: リソース・管理担当

絵素材の制作、演出担当からの報告の確認、push とマージ、節目の実機確認が担当範囲。

## 作業の進め方

1. `assets_manifest.txt` が素材の TODO リスト。本番素材はローカルに置き、リポジトリには入れない。
2. 演出担当の作業ブランチの報告を受けたら、動画とテスト公開で内容を確認し、問題なければ push / マージする。
3. 節目では本番素材を入れた状態で自分の環境で実機確認する（演出担当は画面共有で一緒に見る）。
4. main にマージされたら本番公開（ルート `/`）が自動で更新される。

## 管理まわり

- ルールと運用メモ（`docs/`）の更新は管理担当が行う。作業ブランチは main から派生するので自動で行き渡る。
- Pages の容量（全体 1GB）に注意。マージ済みブランチとその公開フォルダの掃除は管理担当の仕事。
- CI が落ちていないか時々確認する（長期間放置すると Ren'Py や Actions の更新で静かに壊れるため）。
