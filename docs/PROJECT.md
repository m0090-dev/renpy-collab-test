# プロジェクト設定（ここを埋める）

このファイルがプロジェクト固有情報の唯一の入口。他の文書と AI はここを参照する。

## 基本

- プロジェクト名: renpy-collab-test（テスト用）
- ひとことで言うと: 共同制作の流れ（ブランチ→テスト公開→確認→マージ）を一周確認するためのテストプロジェクト
- 使用ツール/エンジン: Ren'Py
  - 取り込んだパック: packs/renpy
  - 取り込んだプリセット: presets/duo-renpy

## 役割

| 役割 | 担当 | 役割メモ |
|---|---|---|
| 演出担当（シナリオ＋演出） | 相方 | docs/roles/ROLE_DIRECTOR.md |
| リソース・管理担当 | 管理者 | docs/roles/ROLE_RESOURCE.md |

- push / マージの権限を持つ人: リソース・管理担当

## 公開

- 本番 URL: https://m0090-dev.github.io/renpy-collab-test/
- テスト公開の形式: 本番 URL + `/<ブランチ名>/`
- 公開まわりの制約: GitHub Pages のサイト全体上限 1GB（ルート＋全ブランチ分）

## 素材ポリシー

- 本番素材をリポジトリに入れるか: 入れない（本番素材は管理担当の手元で管理し、節目に差し替えて実機確認する）
- ダミー素材の要否と作り方: 必要。`tools/make_dummies.py` で `assets_manifest.txt` の一覧から同名・同サイズのダミーを生成する

## このプロジェクト固有のルール追記

- テスト用リポジトリのため、内容は最小限でよい。流れが一周通ることの確認を優先する。
