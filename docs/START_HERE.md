# 開始メモ（マスター・汎用）

このリポジトリで作業を始める AI は、まずこのファイル、`docs/PROJECT.md`、
`docs/RULES.md` を読むこと。
作業ブランチに影響する操作の前に、必ず main の最新版を参照する。

## 手順

1. このファイル、`docs/PROJECT.md`、`docs/RULES.md` を読む。
2. ユーザーに役割を選んでもらう（勝手に決めない）。
   選択肢は `PROJECT.md` の役割表から作る。「確認だけ」は常に含める。
3. 選ばれた役割のメモ（`PROJECT.md` の役割表に書かれたファイル）を読む。
   パートナー向けメモが存在するプロジェクトでは、対象の側のチャットはそれも読む。
4. 最新の main から作業ブランチを作る（命名は RULES に従う）。「確認だけ」なら作らない。
5. 「準備できた。役割は○○、ブランチは○○」と短く報告する。

## 大原則

- main は常に「公開できる状態」。直接の作業は作業ブランチでだけ行う。
- ルールと設定の正本は main の `docs/`。古い・合わないと感じたら、その旨を報告に含める。
- プロジェクト固有の事情（使用ツール、公開方法、素材の扱い）は `PROJECT.md` と
  取り込んだパックの注意書きが優先する。
