# 共同制作テンプレート（汎用）

AI エージェントと一緒に複数人で作るための、リポジトリ土台のテンプレート。
特定のエンジンや相手に依存しない「汎用ベース」に、必要に応じてパックと
プリセットを足して使う。

## 使い方（GitHub のテンプレート機能を想定）

### テンプレート側（1 回だけ）

1. この一式を GitHub のリポジトリに置く。
2. そのリポジトリの Settings → General → 「Template repository」にチェックを入れる。

### プロジェクト側（作品ごとに）

1. テンプレートリポジトリの「Use this template」→「Create a new repository」で
   新しいリポジトリを作る（ファイルだけがコピーされ、履歴は引き継がれない）。
2. `docs/PROJECT.md` を埋める（プロジェクト名、使用ツール/エンジン、役割分担、公開先）。
   ここが唯一の「プロジェクト固有の入口」で、他の文書はここを参照する。
3. 使うエンジンのパックを取り込む（例: `packs/renpy/` の中身を、置き場所に合わせて
   コピーする。ワークフローは `.github/workflows/` へ、ツールは `tools/` へ等）。
4. 役割メモを `docs/roles/` に、雛形（`ROLE_TEMPLATE.md`）から作る。
   プリセットを使う場合は `presets/` の取り込み手順に従う。
5. 相手に合わせた配慮が要る場合は `docs/PARTNER_NOTES_TEMPLATE.md` から
   パートナー向けメモを作る。
6. 取り込みが済んだら、プロジェクト側の `packs/` と `presets/` は削除してよい
   （テンプレート側に残っているものが正本。何を取り込んだかは PROJECT.md に記録する）。
7. 公開や main 保護の設定（ホスティングの有効化、ルールセット等）を済ませる。

### 注意

- テンプレートから作ったリポジトリには、テンプレート側の後の更新は自動で入らない。
  必要な変更は手動で取り込む（プロジェクトごとに独立する、という性質でもある）。
- 自動で届けたい場合は、下の「テンプレート改善の自動取り込み」を使う。

### テンプレート改善の自動取り込み（任意）

- プロジェクト側に `extras/template-sync.yml.sample` を
  `.github/workflows/template-sync.yml` として置くと、テンプレート側の更新が
  定期チェックされ、差分が PR として自動で届く（使うのは
  AndreasAugustin/actions-template-sync）。マージするかは管理担当が決める。
- `extras/.templatesyncignore.sample` をプロジェクト側に置き、プロジェクト固有の
  ファイル（PROJECT.md、埋め済みの役割メモや配慮メモ、素材リスト等）を同期対象から
  外すこと。外さないと固有の内容が上書きされ得る。
- テンプレートが private の場合や、ワークフローファイルまで同期したい場合は、
  SSH 鍵や PAT の追加設定が要ることがある。
- 競合が起きたら通常の PR の競合として解決する。同期は「改善を届ける」までで、
  取り込む判断はプロジェクト側に残る。

## 作業の始め方（どのプロジェクトでも同じ）

自分の AI にこう言うだけ:

> 「このリポジトリを参照して、`docs/START_HERE.md` を見てから作業できる状態にして」

AI は `PROJECT.md` を読み、役割の選択肢を提示し、役割に合ったメモを読んで、
最新の main から作業ブランチを作って「準備できた」と報告する。

## 構成

- `docs/PROJECT.md` — プロジェクト固有の設定（最初に埋める）
- `docs/START_HERE.md` — 全チャット共通の開始手順（マスター）
- `docs/RULES.md` — 共通ルールの核（プロジェクト固有の追記は PROJECT.md 側へ）
- `docs/roles/ROLE_TEMPLATE.md` — 役割メモの雛形
- `docs/PARTNER_NOTES_TEMPLATE.md` — パートナー向け配慮メモの雛形
- `packs/` — エンジン/ツール別の追加物（ワークフロー、ツール、注意点）
- `presets/` — 特定の組み合わせ向けに埋め済みのセット（コピーして使う）
- `extras/` — プロジェクト側に置く任意の追加物（テンプレート同期のサンプル等）
